International Student Enrolment Dashboard

An end-to-end business analysis case study reconstructing the international student admissions lifecycle. Combines Excel analytics with BPMN process modelling to support better planning, faster admissions decisions, and clearer accountability.

Excel BPMN Process Modelling Data Analysis Business Analysis

Project Overview

Purpose. This project reconstructs an end-to-end business analysis case study for the international student admissions lifecycle. The work combines Excel-based analytics with BPMN process modelling to show how enrolment data and operational workflow design can support better planning, faster admissions decisions and clearer accountability.

Dataset at a Glance

  • 138,607 rows covering 2019-2023 Higher Education
  • 437,485 total enrolments (2023)
  • 209,944 commencements (2023)
  • 21.5% year-over-year growth

Work Completed

  • Cleaned and structured a Higher Education dataset covering 2019-2023, with quality checks for row count, missing critical fields, duplicates, year range and sector coverage
  • Built a consultant-style Excel workbook with executive dashboard, annual trend analysis, state summary, provider split, new-student analysis, recommendation register and BPMN reference sheets
  • Applied a clear annual comparison rule: December year-to-date records were used for annual analysis to avoid double-counting cumulative monthly values
  • Designed BPMN views to demonstrate process thinking: a simple end-to-end workflow and a swimlane model showing responsibility across student, admissions, faculty, finance and system/admin roles

Key Insights from the Analysis

  • Market recovery: declined from 440,856 enrolments in 2019 to 360,026 in 2022, before recovering to 437,485 in 2023 — a sharp post-decline recovery, but not a full return above the 2019 level
  • Commencements as a leading indicator: grew from 147,017 in 2022 to 209,944 in 2023 (42.8% increase), making them useful for future workload, offer conversion and capacity planning
  • State concentration: NSW was the largest 2023 state with 166,414 enrolments, followed by VIC with 132,102 — these represent the main operational concentration in the admissions pipeline
  • Provider split: Government providers accounted for 354,494 enrolments in 2023 vs 82,991 for non-government — most activity sits in the government segment
  • New vs continuing: New-student enrolments reached 154,660 in 2023, compared with 282,825 continuing-student enrolments, highlighting the need to monitor front-end application quality, document readiness and payment confirmation closely

Business Analysis Interpretation

The dashboard turns a raw enrolment dataset into a decision-support artefact. From a business analysis perspective, the value isn't only the charting. The workbook shows how raw data can be governed, summarised and translated into operational questions: where demand is concentrated, which indicators signal future workload, and where a redesigned admissions process can reduce delays. The analysis supports practical recommendations such as earlier document checks, clearer qualification gateways, stronger faculty escalation rules and faster finance confirmation before Confirmation of Enrolment release.

BPMN Process Model

Process scope. The BPMN model represents the admissions journey from student application submission through eligibility review, offer decision, acceptance, payment confirmation and COE release. The swimlane format highlights accountability across the student, admissions team, faculty/admin officer, finance and system/admin support roles.

Process Improvement Recommendations

  • Move document validation earlier in the workflow so incomplete applications are identified before detailed assessment begins
  • Use explicit gateways for qualification, offer type and student acceptance so exceptions are visible instead of hidden inside manual follow-up
  • Create a clear escalation path for faculty or RPL advice to reduce uncertainty when assessment requires specialist input
  • Link finance confirmation to COE issuance so the final output is controlled, auditable and aligned with admissions policy
