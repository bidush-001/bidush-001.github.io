Vodafone Customer Churn Prediction

An end-to-end machine learning project predicting which telecom customers are likely to leave, with explainable AI to drive retention strategy.

Machine Learning XGBoost SHAP Flask REST API Python SMOTE

Project Overview

Customer churn (when subscribers leave a service) is a major issue for telecom companies like Vodafone. Retaining existing customers is 5x cheaper than acquiring new ones.

This project applies data science and machine learning to predict customer churn, helping Vodafone identify at-risk customers early and act with retention strategies. I built this project end-to-end: from data preprocessing and exploratory analysis to model development, explainability, and deployment.

Tools & Technologies

  • Languages & Libraries: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost, SHAP
  • Data Preprocessing: Missing value imputation, OneHotEncoding, SMOTE (balancing classes)
  • Modeling: Logistic Regression, Random Forest, XGBoost
  • Evaluation: ROC-AUC, Precision-Recall curves, Confusion Matrix, Classification Reports
  • Explainability: SHAP values for local & global feature importance
  • Deployment: Flask REST API, Joblib for model persistence
  • Version Control & Documentation: Git/GitHub, Jupyter Notebooks, Markdown

Process & Methodology

1. Data Understanding & Cleaning

  • Dataset: Vodafone Customer Churn dataset from Kaggle (~7,000 rows, 23 features)
  • Target variable: Churn (1 = Yes, 0 = No)
  • Handled missing values (median for numerical, mode for categorical)
  • Encoded categorical variables using OneHotEncoding
  • Balanced dataset with SMOTE to avoid bias toward majority class

2. Exploratory Data Analysis (EDA)

  • Churn Imbalance: 26% churners vs. 74% non-churners
  • Tenure Effect: Shorter-tenure customers more likely to churn
  • Charges: Higher monthly charges correlate with higher churn
  • Contract Type: Month-to-month contracts are the riskiest
  • Support Services: Lack of TechSupport/OnlineBackup increases churn risk

3. Model Development

Compared three models: Logistic Regression, Random Forest, and XGBoost (final choice).

  • ROC-AUC ~0.92-0.93 across all models
  • Precision-Recall curves show XGBoost outperforming under imbalance
  • Confusion matrices & reports confirm balanced performance

Final chosen model: XGBoost, with threshold tuned to 0.6 for best trade-off between precision and recall.

4. Explainability

Used SHAP to identify drivers of churn. Key findings:

  • Contract type (month-to-month contracts are highly risky)
  • Payment method (electronic check correlates with higher churn)
  • Tenure and monthly charges play major roles
  • Support services like TechSupport and OnlineBackup reduce churn risk

5. Deployment

  • Exported final pipeline as churn_pipeline_artifacts.joblib
  • Built a Flask REST API endpoint /predict that accepts customer data in JSON and returns prediction (churn or not), probability score, and decision threshold used

Findings & Recommendations (Business Perspective)

Problem: Customer churn leads to revenue loss and lower customer lifetime value.

Key Findings

  • Month-to-month customers are much more likely to churn
  • New customers (low tenure) are high-risk
  • Customers paying via electronic check are unstable compared to auto-pay
  • High monthly charges without value perception drive churn
  • Lack of add-on services (TechSupport, Backup) strongly correlates with churn

Recommendations

  • Incentivize long-term contracts with discounts/loyalty perks
  • Strengthen new customer onboarding to reduce early churn
  • Promote auto-pay to replace electronic checks
  • Reassess high-pricing models; bundle services to improve value perception
  • Offer free trials of support services to drive adoption

Business Impact

By focusing retention strategies on these high-risk groups, Vodafone can reduce churn significantly, cut acquisition costs, and boost long-term profitability.
